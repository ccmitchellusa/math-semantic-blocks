The bounded converter includes native MathML DOM output, matrix and derivation
environments, piecewise definitions, vector calculus, multiple and contour
integrals, statistics, set and graph notation, and common AI/ML and tensor
notation, plus the everyday KaTeX/MathJax symbol, sizing, annotation and
Dirac-notation set pinned by test/fixtures/coverage.json. Unsupported
environments, package commands, and custom macros remain explicitly rejected.
The optional mathml.css file supplies table-cell alignment, \tag labels and
the \boxed/\cancel enclosures for MathML Core browsers while preserving
MathML column alignment hints.
